# 🎓 Ostadban

**Ostadban** is an AI-assisted web platform that helps university students make informed course selection decisions by providing professor ratings, student reviews, and AI-generated insights.

Built with Laravel, the platform combines community-driven feedback with Google Gemini AI to summarize student experiences and highlight meaningful patterns across reviews.

---

## ✨ Features

### 👨‍🎓 Student Features

- User registration and authentication (JWT)
- Email verification
- Browse and search professors
- View professor profiles
- View average ratings
- Read student reviews
- Submit ratings and reviews
- View courses taught by each professor

---

### 🤖 AI-powered Review Analysis

Powered by **Google Gemini 2.5 Flash**

For every professor, the AI analyzes all submitted reviews and automatically generates:

- Review summary
- Strengths
- Weaknesses
- Suitable student profile
- Overall evaluation
- Confidence score

This helps students understand professors without reading dozens of reviews.
